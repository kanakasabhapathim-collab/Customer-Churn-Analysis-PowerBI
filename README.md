# Customer Churn Analysis | Power BI

## Project Overview
This project analyzes customer churn data using Microsoft Power BI to identify patterns across contract types, customer tenure, payment methods, and internet services.

## Objectives
- Measure overall customer churn.
- Identify customer segments with high churn counts and rates.
- Build an interactive dashboard to support retention decisions.
- Present actionable business recommendations.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning and Visualization

## Key Performance Indicators
- Total Customers: 1,800
- Churned Customers: 352
- Overall Churn Rate: 19.56%

## Analysis Performed
- Customer churn by contract type
- Customer churn by tenure group
- Customer churn by payment method
- Customer churn by internet service
- Churn rate comparison by contract type

## Key Findings
- Month-to-month contracts have the highest churn rate among known contract types.
- Customers in the 0–12 month tenure group have the highest churn count.
- Electronic Check users have the highest churn count by payment method.
- Fiber optic users have the highest churn count by internet service.

## Recommendations
- Investigate customer experience issues during the first year.
- Explore retention offers for month-to-month customers.
- Review feedback from customers using Electronic Check.
- Investigate service quality and pricing concerns among Fiber optic customers.
